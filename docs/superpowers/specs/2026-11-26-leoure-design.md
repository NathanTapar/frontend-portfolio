# Leoure freelance portfolio

Approved direction: a sample freelance frontend portfolio for Leoure. The owner uses HTML, CSS, JavaScript, and Figma. One personal concept project replaces the earlier three-project proposal.

## Experience
A single responsive page introduces Leoure, explains three services, presents one original live concept landing page, gives a concise approach, and opens a project inquiry dialog. The concept is a fictional coffee studio, Stillday. Its separate demo page is explicitly labeled and links back to the portfolio. No client history, results, availability, testimonials, or location is invented.

## Visual direction
Quiet studio: frost #EDF4FA, paper #F9FBFD, ink #172D42, muted ink #53677C, blue #295F9B, and line #CDDCE8. Manrope sans-serif with a local system fallback. Oversized left-aligned introduction, an offset browser preview, generous spacing, and a full-width project image. Avoid a repeated card grid and decorative statistics. Native hover, focus, menu, dialog, and selected-state feedback; respect reduced motion.

## Content and interaction
Navigation: Work, Services, About, and a contact action. Primary actions lead to the project and inquiry dialog. One project links to demo/index.html and an expandable explanation. The inquiry collects name, email, type, and brief. Without a configured recipient it copies a clearly labeled unsent brief; with a real recipient it opens an email draft. The page explicitly identifies its unconfigured contact setup. Never simulate delivery. Native validation, dialog focus behavior, visible keyboard focus, mobile navigation, and no horizontal overflow are required.

## Delivery
Use plain HTML, CSS, and JavaScript, with no build dependencies. Keep assets local. Add clear README setup and contact customization instructions. Test desktop and mobile layouts, navigation, live demo, inquiry validation and copying, focus/Escape, reduced motion, and local links.
